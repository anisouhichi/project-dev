# ✈️ Pipch Travels – Travel Agency Management System

A modern and responsive travel agency management application developed using **HTML**, **CSS**, **JavaScript**, and **JSON**.

The platform allows users to browse available trips, register customers, calculate travel costs, manage bookings, generate receipts, and store reservation data locally.

---

## 🚀 Features

### 🌍 Travel Catalog
- Browse available travel destinations
- View departure dates and available seats
- Search destinations instantly
- Filter trips by maximum price
- Sort trips by:
  - Closest departure date
  - Furthest departure date
  - Lowest price
  - Highest price

### 📝 Customer Registration
- Register travelers with:
  - First Name
  - Last Name
  - Passport Number
- Passport validation system
- Companion management

### 🎁 Additional Services
Choose optional services depending on the selected trip:

- Travel Insurance
- Guided Tours
- Transportation Passes
- Airport Transfers
- Special Activities

### 💳 Payment Management
Supports multiple payment methods:

- Cash Payment
- Check Payment

Includes validation for check numbers.

### 💰 Dynamic Price Calculation
Automatically calculates:

- Base trip price
- Companion costs
- Optional services
- Total amount payable

### 🧾 Booking & Receipts
- Save reservations locally using Local Storage
- Display booking history
- View payment information
- Clear all stored receipts

### 🌙 User Experience
- Responsive Design
- Dark / Light Mode
- Real-time Notifications
- Smooth Navigation
